Votre carnet de rencontres sur iPhone

Application Réseau

Notez en dix secondes qui vous avez rencontré et de quoi vous avez parlé. Claude transforme ensuite vos notes en fiches, et vous retrouvez tout avant le prochain événement.

Vos données restent chez vousSur votre iPhone et dans votre dossier synchronisé. Personne d'autre n'y a accès.
Aucune intelligence dans l'appC'est votre Claude qui fait le tri, quand vous le décidez.
Fonctionne hors ligneUne vraie app sur l'écran d'accueil, utilisable d'une main.

Comment ça marche

  1. 1. NoterPendant ou après un échange, vous tapez ou dictez en vrac.
  2. 2. ExporterUn fichier part dans votre dossier synchronisé.
  3. 3. Claude traiteIl crée les fiches, les anniversaires et les suivis promis.
  4. 4. ImporterVos fiches à jour reviennent dans l'app.

Avant un événement, l'onglet « Préparer » vous montre qui vous risquez de revoir : nom, métier, dernier sujet abordé, un détail personnel, et ce que vous lui aviez promis.

Ce qu'il vous faut

  • Un iPhoneL'app a été testée sous iOS 26, installée depuis Safari.
  • Un ordinateur avec Claude CodeL'application Claude pour ordinateur (onglet Code) ou Claude Code dans un terminal, avec un abonnement Claude qui y donne accès.
  • Un dossier synchronisé entre l'ordinateur et l'iPhoneiCloud Drive, OneDrive, Google Drive ou Dropbox.
  • Un compte GitHub gratuitIl héberge votre copie de l'app. Vous pourrez le créer pendant l'installation.
  • Facultatif : Google Agenda et NotionPour que Claude y crée vos anniversaires et vos suivis. D'autres outils sont possibles.

Installation

Comptez 30 à 45 minutes. Claude vous guide d'un bout à l'autre, une étape à la fois.

  1. Décompressez le kit dans votre dossier synchronisé

    Ouvrez le fichier application-reseau-kit.zip reçu avec cette page, puis placez le dossier application-reseau-kit dans votre iCloud Drive, OneDrive, Google Drive ou Dropbox. C'est ce qui permettra à votre iPhone et à Claude de s'échanger des fichiers.

  2. Ouvrez Claude Code dans ce dossier

    Démarrez une nouvelle session de Claude Code en choisissant le dossier application-reseau-kit comme dossier de travail.

  4. Laissez-vous guider

    Claude vous donne une étape à la fois et attend votre réponse avant de continuer. Si vous êtes interrompu, rouvrez Claude Code dans le même dossier et dites « reprends l'installation ».

    • créer votre compte GitHub et vous y connecter (Claude ne voit jamais vos mots de passe) ;
    • approuver les actions que Claude vous propose ;

  • Quand vous voulez faire le pointOnglet Sauvegarde, « Exporter », vers le dossier donnees/exports.

Questions fréquentes

Quelqu'un d'autre peut-il voir mes notes ?

Non. L'app n'a ni serveur ni compte : vos notes restent sur votre iPhone, et les fichiers d'échange dans votre propre dossier synchronisé. Seul le code de l'app est publié sur votre compte GitHub, jamais vos données. La personne qui vous a envoyé ce kit n'a accès à rien de ce que vous saisissez.

Combien ça coûte ?

L'app et son hébergement sur GitHub sont gratuits. Il vous faut seulement un abonnement Claude donnant accès à Claude Code.

Ça marche sur Android ?

L'app a été conçue et testée sur iPhone uniquement. Elle s'ouvre probablement sur Android, mais rien n'est garanti.

Et si je perds ou change de téléphone ?

Chaque export est une sauvegarde datée dans votre dossier synchronisé. Réinstallez l'app depuis votre adresse, puis importez votre fichier le plus récent : tout revient.

Puis-je corriger une fiche directement dans l'app ?

Non, c'est voulu : les fiches sont tenues par Claude, pour éviter les conflits. Pour corriger quelque chose, écrivez simplement une note, et Claude mettra la fiche à jour au prochain traitement.

Comment recevoir les nouvelles versions ?

Vous aurez votre propre copie, indépendante. Si on vous envoie un kit plus récent, décompressez-le à côté de l'ancien et demandez à Claude de « mettre à jour l'app avec ce kit » : il ne touchera pas à vos données.
